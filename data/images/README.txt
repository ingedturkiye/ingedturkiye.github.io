Event & News Photos
───────────────────
Place event photos in this folder, then reference them in data/events.js
using a relative path like:

  "image": "data/images/conference-2026.jpg"

Tips:
- Recommended size: around 800×500 px (landscape)
- Keep file sizes reasonable — under 300 KB is ideal for web
- Accepted formats: .jpg, .jpeg, .png, .webp
- If an event has no photo, just leave the image field as "" or remove it
